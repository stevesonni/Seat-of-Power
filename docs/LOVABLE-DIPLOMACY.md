# Lovable art: the President's diplomacy (sky-blue letters)

The game works now with stand-in pictures. These replace them; Claude puts each one where it belongs.

**Style:** as the rest of the pack: flat-shaded cartoon with bold outlines. All people are fictional and unnamed: no real presidents, prime ministers or the real UN Secretary-General. Real countries, cities and the UN are fine. No national flags or logos close enough to read as real ones, except the UN's blue colour. No text on the pictures. WebP.
