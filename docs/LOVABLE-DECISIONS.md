# Lovable: a picture for every decision (Packs 8–13)

Today only some decisions have their own picture (the ghost-workers purge, the crises, revenue measures). Every bill, programme, order, crisis, media story, court case, invitation and investor should have one. Each picture shows **twice**: at the top of the decision, and again on its result card (or as the photo on the newspaper front page).

## Rules for every picture
- **Style:** the same painted, warm, semi-realistic illustration style as the game's existing scenes (for example `scenes/ghost-workers-purge`, `scenes/money-*`). Not 3D.
- **Size:** 1600×900 (16:9), WebP or PNG, **no transparency**. Keep the main subject in the middle 60% (phones crop the edges).
- **Setting:** Nigeria. Real places can be suggested (markets, highways, a state secretariat), but **no real people**:
  - no recognisable politicians, presidents, kings or celebrities;
  - foreign leaders are shown from behind, as hands in a handshake, or as a generic official.
- **No text:** no readable words, logos, party symbols or the national crest. Small background flags are fine.
- **File names:** exactly as listed, in a folder `decisions/` (for example `decisions/land_reform.webp`).
